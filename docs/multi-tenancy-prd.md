# new-api 组织功能产品需求

适用范围：new-api 主仓库（Go 服务端、React 控制台、主数据库与日志数据库）。技术落点见 [设计](multi-tenancy-design.md)，发布操作见 [交付说明](multi-tenancy-implementation.md)。

## 产品边界

平台管理上游渠道、模型价格和套餐；组织自助创建并采购，成员各自登录和创建 API Key，费用从组织共享资金中结算。成员消费上限不是独立钱包，不做组织自带渠道、组织级定价或支付密钥覆盖。

个人用户继续直接使用自己的资源、钱包和订阅，无需创建组织。没有团队时隐藏组织切换器，组织设置保留创建入口。个人和组织资源通过明确作用域隔离，平台管理员使用独立平台管理入口。

## 角色

| 能力 | Owner | Admin | Member |
| --- | --- | --- | --- |
| 管理自己在组织中的 API Key | 是 | 是 | 是 |
| 查看自己的用量与剩余可用额度 | 是 | 是 | 是 |
| 查看组织成员及全部用量 | 是 | 是 | 仅自己 |
| 邀请、调整与停用非 Owner 成员 | 是 | 是 | 否 |
| 采购、充值、账单、预算与组织设置 | 是 | 是 | 否 |
| 发起所有权转让、停用或删除组织 | 是 | 否 | 否 |

组织角色不赋予平台管理权限。普通组织接口不允许平台角色绕过成员检查；平台组织管理单独鉴权。

## 核心流程

- **创建与切换**：输入名称和唯一 Slug，创建者成为 Owner；切换个人或组织后清理旧页面缓存和表单，重新加载权限。已提交请求保留原组织归属，延迟响应不能污染新页面。
- **邀请**：Owner/Admin 输入已注册且启用账号的精确用户名和角色。接收人在通知中心接受或拒绝，不要求邮箱。邀请默认七天有效，可撤销或重发；成员加入受套餐席位限制。改名不会改变邀请接收账号。
- **API Key**：所有角色只管理自己的 Key。组织 Key 的 Secret 仅创建时显示；个人 Key 保留原有查看能力。成员停用/移除禁用其组织 Key，恢复后需本人重新启用。
- **采购**：Owner/Admin 查看适用套餐，使用组织余额或现有在线支付渠道购买。订单归属与购买条款持久化，重复支付回调不重复入账。分组权益作用于组织，不修改个人分组。
- **用量与预算**：组织订阅优先，钱包按溢出策略兜底；成员上限限制预留和已结算消费。Owner/Admin 可查看成员与模型用量，普通成员只看自己的明细。组织预算触发邮件/Webhook 告警。
- **设置**：允许名称、Logo、通知地址、默认成员上限、预算告警和模型范围收窄；组织设置不能扩大平台授予的模型权限。
- **生命周期**：停用阻止新请求，保留历史数据和已预扣请求结算。Owner 转让必须由目标成员确认。余额、有效订阅、待支付或未完成请求未处置前不得删除。平台封禁只能由平台解除。

## 页面与接口边界

控制台包括个人/组织概览、API Key、用量日志、组织成员、账单、套餐订单和组织设置。平台渠道、模型定价、套餐定义与系统设置独立展示。

普通请求以有效的 `X-Org-Id` 选择组织，省略即个人。组织管理接口要求有效组织上下文。Relay 按 Key 的归属处理，不允许请求参数改变资金主体。平台看板和日志使用 `/platform/dashboard/:section` 与 `/platform/usage-logs/:section`。

## 验收要求

- 个人、不同组织及平台入口隔离覆盖列表、详情、筛选、批量操作、任务制品和日志脱敏。
- 模型、IP、Key 限额、成员周期上限及组织资金共同约束请求；计费不得溢出为负费用。
- 支付、结算和退款幂等；跨周期退款不增加新周期额度，失效成员的历史账务可完成。
- 权限与组织配置变更在后续鉴权中读取当前数据库状态，不依赖过期的组织缓存。
- 页面文案支持 en、zh、zh-TW、fr、ja、ru、vi，切换组织和登录身份不得显示旧响应。
- 使用真实 SQLite、MySQL、PostgreSQL 验证行为、新建和正式版升级；共享路径覆盖独立日志库，迁移重复启动保持数据、索引和约束。
- 整体停机升级，不分阶段混跑旧、新版本；回滚使用升级前快照与匹配旧版本，并先处理上线后的增量账务。
